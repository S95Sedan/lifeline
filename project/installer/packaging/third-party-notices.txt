Lifeline native installer - third-party components

Installer.exe statically links a minimal FFmpeg 8.1.3 build for movie conversion.
Only the required disc decoders, H.264/AAC output, MP4 support and image scaling
are enabled. H.264 encoding uses the Windows Media Foundation encoder.
No FFmpeg executables or DLLs are installed with the game.
The FFmpeg LGPL version 2.1 license accompanies this file as LICENSE-ffmpeg.txt.
Unmodified upstream source:
https://ffmpeg.org/releases/ffmpeg-8.1.3.tar.xz
SHA256: 7138d28c96d9d3e3af4ee3d8cad72741f8ffb40da90c1112235dea3ecd3178a3
The build recipe and converter source are in project/installer in this project.
Rebuilding the installer against modified FFmpeg libraries is permitted.

JSON for Modern C++ 3.12.0 is used by the installer.
https://github.com/nlohmann/json/releases/tag/v3.12.0
